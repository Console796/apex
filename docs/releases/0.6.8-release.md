# Apex 0.6.8-release: realtime lighting preview

Apex is a native level editor for Source-engine maps, built for the Strata Source (Portal 2: Community
Edition) toolchain. It reads and writes `.vmf` files, edits them in any number of Vulkan viewports,
compiles them with the real Source tools, launches the game, and previews lighting in the editor.
It is written in C++23 with Qt 6 and Vulkan, it runs natively on Linux and Windows, and it is MIT
licensed.

This release completes milestone 0.6, the realtime lighting preview. Since
[0.6.5](https://github.com/Console796/apex/releases/tag/v0.6.5), Lit mode has gained light clusters,
`light_rt`, shadows, sky, fog and cubemaps, and it now uses the game's display curve.

> ## Please read this!
>
> **Apex is still unfinished, pre-release software.** It is not a replacement for Hammer yet, and it
> will crash, lose your place, or do the wrong thing.
>
> - **Back up every map before you open it in Apex.** Saving an unmodified file is byte-identical,
>   but edits are not guaranteed to be safe.
> - **Lit mode shows direct light only.** It has no bounced light, so rooms lit mainly by bounce
>   look much darker than in game. Baked bounce preview is milestone 0.7.
> - **Only Portal 2: Community Edition has been tested.** Other Source games may work, partly work,
>   or not work at all. See
>   [docs/source-game-support.md](https://github.com/Console796/apex/blob/v0.6.8-release/docs/source-game-support.md).
> - **Windows is less tested than Linux.** The full automated test suite, including the GPU tests,
>   now runs on a real Windows machine with an NVIDIA GPU. The Windows installer and zip themselves
>   have had little use on other machines.

## New since 0.6.5

**Lighting preview (Lit mode)**
- **Light clusters.** Lights are binned into a screen-space grid, so maps with many lights stay
  interactive. If a cluster holds more lights than it can, the status bar shows how many were
  dropped. Each light's preview range shows as a sphere on its helper.
- **`light_rt`.** Its direct, specular and indirect modes are read from the entity. Static and
  dynamic direct light and specular are shown. Indirect-only lights add nothing yet and are labelled
  "baked in 0.7".
- **Shadows.** Spot, point and sun lights cast shadows from brushes and props. Shadows follow
  VRAD's caster rules and honour `disableshadows`. A shadow atlas holds them, and lights that don't
  fit are reported on the status line.
- **Sky, fog and cubemaps.** The worldspawn sky is drawn behind the scene, with the 3D skybox around
  `sky_camera`. `env_fog_controller` adds distance fog. `env_cubemap` probes are rendered in the
  editor and rebuilt after nearby edits, and a stale probe is badged on its helper. Strata's
  parallax-corrected cubemaps are supported.
- **The game's display curve.** Lit now uses the sRGB curve that matches the game's screenshots, in
  place of a 2.2 power curve. Mid-tones and darks are closer to the game's.
- **Materials.**
  - EverythingPBR's door icons show the right colour and are no longer white. Additive materials
    (`$additive`) blend as additive, and `$color2` is applied.
  - A VMT patch's `insert` block now overrides keys from the included material, as the game does.
  - Portal 2's light covers are deeper. The strip no longer repeats at grazing angles or shows
    black stripes.

**Viewports and editing**
- Back faces are culled in Textured, Flat and Lit views, which is faster and closer to the game. A
  "Backface culling" toggle in each viewport's Overlays menu draws both sides again.
- Opening a map mounts the installed addons it needs, so a map that uses an addon you haven't enabled
  no longer shows missing textures and models.
- Hammer compile profiles imported from `cmdseq.wc` keep the game step as non-waiting.
- If no usable Vulkan device is found, Apex shows a dialog asking you to install graphics drivers.

**Look and feel**
- New default theme, Pointfile (ink black with a red accent), plus a light companion, Pointfile Paper.
  Both use IBM Plex Sans, which ships with Apex. The classic Dark and Light themes are still in
  Settings.
- Apex windows have an app icon. The Linux `.deb` and `.rpm` install a desktop entry and icon, so
  Apex appears in application menus with its icon.

**Windows**
- Viewports work on Windows. In 0.6.5 every viewport reported that the platform had no Vulkan
  surface.
- The Windows zip now carries the Visual C++ runtime, so it runs without installing the VC++
  redistributable.
- New: a Windows installer (`.exe`) with a Start menu shortcut and an uninstaller.

## How close is the lighting?

Apex's Lit mode was compared with in-game screenshots of a test map, taken at pinned exposure and
with the map compiled without bounce, so both sides show direct light only:

- **Light relative to surface colour matches.** Light falloff, spot cones and sun/sky behave like
  VRAD's. Irradiance matches VRAD `-bounce 0` within a mean of 2% on flat, unoccluded surfaces.
- **Overall brightness is about 1.25× the game.** The same excess appears in fullbright, so it comes
  from how surfaces respond, not from the lights. The cause is still being investigated (EverythingPBR's
  diffuse response in game is the leading candidate).
- **Against the shipped map with its baked bounce, Apex is darker.** It is about 0.7× overall and
  about half in shadowed areas, because bounce is not previewed.

The test map renders at about 16 ms a frame on the development machine.

## What is missing

- **Bounced light and ambient occlusion are not previewed** (milestone 0.7). Lit will not match
  what VRAD bakes in indirectly lit areas.
- **No displacements and no overlays** (milestone 0.8). Maps that use them can be opened, but you
  cannot edit them in Apex.
- **No plugins or scripting** (milestone 0.9).
- **No user manual.** The project documentation is aimed at developers.
- The Linux tarball ships without the Qt Multimedia plugin, so sound preview playback is not
  available from it. The `.deb` and `.rpm` use your system's Qt Multimedia.
- Only the Strata/P2CE game profile exists.

The full plan is in [docs/roadmap.md](https://github.com/Console796/apex/blob/v0.6.8-release/docs/roadmap.md).

## Downloads

All files are version `0.6.8.74`: milestone 0.6, sub-milestone 8, build 74.

| Platform | File | Notes |
|---|---|---|
| Debian, Ubuntu | `apex_0.6.8.74_amd64.deb` | Uses your system Qt (6.10.2 or newer) |
| Fedora, RHEL family | `apex-0.6.8.74-1.x86_64.rpm` | Uses your system Qt (6.10 or newer) |
| Any Linux, x86_64 | `apex-0.6.8.74-release-linux-x86_64.tar.xz` | Bundles Qt; run `./apex` |
| Windows 10/11, x64 | `apex-0.6.8.74-release-windows-x64.exe` | Installer |
| Windows 10/11, x64 | `apex-0.6.8.74-release-windows-x64.zip` | Portable; run `apex.exe` |

SHA-256 checksums for all five files are in `SHA256SUMS`.

All Linux packages were built on Ubuntu 26.04 and need **glibc 2.43 or newer**. On an older
distribution, build from source.

The Windows files are not code-signed, so Windows SmartScreen may warn when you run them.

You need a GPU and driver with Vulkan 1.3. The packages do not include the Vulkan loader or any GPU
driver.

```bash
sudo apt install ./apex_0.6.8.74_amd64.deb
```

```bash
sudo dnf install ./apex-0.6.8.74-1.x86_64.rpm
```

```bash
tar -xf apex-0.6.8.74-release-linux-x86_64.tar.xz && ./apex-0.6.8.74-release/apex
```

Apex needs a game install to be useful. Point it at a P2CE install and open a `.vmf`.

## Please tell us what breaks

**Please [open an issue](https://github.com/Console796/apex/issues) for anything that goes wrong.**
That includes crashes, maps that fail to open or save, geometry that looks wrong, lighting that does
not match the game, and anything confusing. A rough report is better than none.

A good issue says:

- what you did, what you expected, and what happened instead;
- your OS and version, GPU and driver, and which package you used;
- the game and, if you can share it, the map (or a cut-down map that shows the problem);
- the log, which is in Apex's log panel.

Lighting comparisons are especially useful now. A screenshot from the game and one from Apex's Lit
mode at the same position (`cl_showpos 1`, `setpos`/`setang`) make a mismatch easy to chase. Reports
from Windows and from games other than P2CE are welcome too.
