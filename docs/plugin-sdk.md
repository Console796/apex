# Apex plugin SDK

The plugin SDK documentation lives in [`docs/plugins/`](plugins/README.md), one page per interface plus
getting started, threading and memory rules, versioning and the examples. It ships in the SDK archive
(`apex-plugin-sdk-<version>.zip`, `share/doc/apex-sdk/`) and is checked against the headers and examples by
`tools/check_docs.py`. This file only points there.
